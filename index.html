Les registres de la table

Trois outils pour jouer, solo avec l’Oracle ou à plusieurs : créer ses Marchefleurs, tenir la campagne séance après séance, tirer ce qui se dresse sur la route.

Registre de la Table la campagne Le compte rendu des séances avec les jets, les dégâts et les PV dedans, les personnages, les fiches de PNJ et le réseau de leurs liens, la progression. À plusieurs, chacun sur son ordinateur. Registre du Havre les personnages Créer un personnage selon le livre, l’imprimer, l’exporter en Word, ou l’enregistrer en .json pour le faire entrer dans la Table. Registre des Rencontres les adversaires Tirer une rencontre à la mesure du groupe, tenir le bestiaire maison et ses familles, donner des traits à une créature.

Jouer à plusieurs

Chaque navigateur garde sa propre copie de la table. Pour la partager, le Registre de la Table propose trois chemins :

  1. Par GitHub. Un dépôt privé garde la table. Chaque changement y part tout seul, les autres le reçoivent dans les dix à trente secondes, et chaque version reste dans l’historique du dépôt.
  2. Par un dossier partagé. Le fichier de table posé dans Drive, OneDrive ou Dropbox, synchronisé sur chaque ordinateur. Il faut Chrome ou Edge.
  3. Par un .json. On l’enregistre, on l’envoie, l’autre l’importe. Tout se fusionne sans rien écraser.

Relier la table à GitHub

  1. Crée un dépôt privé, faelorenn-table par exemple, et coche « Add a README file » pour qu’il ne soit pas vide.
  2. Crée un jeton : Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token. Dans Repository access, choisis seulement ce dépôt. Dans Permissions, mets Contents en Read and write. Donne-lui une date d’expiration.
  3. Dans le Registre de la Table, section « La table », ouvre « Synchroniser par GitHub », colle ton-nom/faelorenn-table et le jeton, puis « Relier à GitHub ».
  4. Donne le même dépôt et le même jeton à ceux qui jouent avec toi, par un message privé. Un jeton à accès fin ne sert que pour les dépôts de son propriétaire : les autres ne peuvent pas s’en faire un pour le tien.

Le jeton n’ouvre que ce dépôt-là, et il reste dans le navigateur où on l’a collé. S’il se perd, supprime-le sur GitHub et crée-en un autre : la table n’en souffre pas.

GitHub accepte 500 écritures par heure et par jeton. La table regroupe les changements et n’écrit jamais deux fois en moins de quinze secondes, ce qui laisse de la marge même à deux pendant une séance chargée.

Ce que ce site montre

Le site est public : avec un compte GitHub gratuit, le dépôt qui l’héberge doit l’être, et n’importe qui peut lire le code des registres, avec ce qu’il contient du livre (peuples, Pratiques, bestiaire).

Vos personnages et vos séances ne sont jamais dans ce dépôt-là. Ils restent dans vos navigateurs, et dans votre dépôt privé si vous reliez la table à GitHub.
